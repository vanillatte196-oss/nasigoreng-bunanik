# Nasi Goreng Bu Nanik - Ungaran Barat

Website profil dan etalase digital sederhana untuk **Nasi Goreng Bu Nanik**, warung kuliner legendaris yang berlokasi di **Ungaran Barat, Kabupaten Semarang**.

## 🚀 Tentang Proyek

Proyek ini dibuat sebagai wadah (repository) di GitHub untuk memperkenalkan menu andalan Nasi Goreng Bu Nanik secara online dan mengarahkan pelanggan langsung ke platform pemesanan (GoFood & WhatsApp).

## 📂 Struktur File

- `index.html` : Halaman utama website yang berisi tata letak dan tombol interaktif pemesanan.
- `style.css` : Lembar gaya (stylesheet) untuk mempercantik tampilan visual agar responsif di ponsel.

## 🔗 Cara Menjalankan

1. Unggah file `index.html`, `style.css`, dan `README.md` ke dalam satu repository GitHub.
2. Aktifkan **GitHub Pages** melalui menu _Settings_ > _Pages_.
3. Website siap diakses secara online!
